# Composition Patterns and Originality Rules

## Basic Structure Types

Choose one structure type — don't mix too many.

### Workflow

Suitable for: input -> processing -> output, content production, AI workflows, automation chains.

How to draw: input on the left, Xiaohei or a strange machine processing in the middle, output on the right, orange arrows showing the main flow direction.

### System Partial

Suitable for: information sources, filters, databases, renderers, agent system components.

How to draw: only draw 3-5 core modules, with Xiaohei participating in one key action.

### Before/After Comparison

Suitable for: chaotic/organized, manual/automated, scattered/consolidated, anxious/stable.

How to draw: chaos on the left, stability on the right, orange arrow in the middle. Characters can be more exaggerated.

### Role State

Suitable for: user pain points, creator states, tool overload, information anxiety, from stuck to flowing.

How to draw: 2-4 small states, each with a short annotation.

### Concept Metaphor

Suitable for: content factory, information warehouse, brain black box, workflow machine, automated daily report.

How to draw: one large strange object or machine, a few inputs, one output. Must have a memorable hook.

### Method Layers

Suitable for: methodology frameworks, system hierarchy, capability stack, content system layers.

How to draw: stacked boxes layer by layer — not a formal pyramid; Xiaohei is beside it building, carrying bricks, or assembling.

### Map Route

Suitable for: from idea to launch, user journey, content handoff path, learning roadmap.

How to draw: one winding path, a few nodes, Xiaohei guiding or walking along.

### Mini Comic Panels

Suitable for: failure to success, real-life process, commentary, before/after usage changes.

How to draw: 2-4 small scenes, each panel expressing only one action.

## Original Metaphor Generation Method

Every time, reinvent a metaphor from the current article — never copy old illustrations.

### Three Steps

1. Replace the abstract concept with a physical action: stuck, leaking, getting heavier, sorting, settling, fermenting, opening a door, folding, unpacking, flowing back.
2. Replace the system structure with a low-tech object: broken machine, cardboard box, drawer, pipe, mailbox, strange gauge, scale, well, ladder, weird workstation.
3. Have Xiaohei perform the action: not standing beside, but stuck inside a machine, pulling the wrong wire, guarding a door, carrying, repairing, weighing, propping up a ladder, recording, stuffing things into some strange device.

### Available Object Pool

- Cardboard boxes, drawers, old machines, funnels, scales, mailboxes, doors, wells, ladders, pipes, thread tangles, floodgates, turntables, black boxes, hole punchers, pasta machines, clotheslines, strange workstations.
- When using, pick only 1-2 — don't pile them up.

### Xiaohei Action Pool

- Pull, carry, stuff, scoop, press, weigh, sew, cut, twist, guard, push, catch, disassemble, label, recycle.
- The action must serve the core meaning — don't be strange just for strangeness's sake.

## Anti-Copying Rules

Do not open or copy from `assets/examples/` by default. These images are only for style calibration — line density, whitespace, color restraint, Xiaohei's character quality.

Unless the user explicitly says "copy this one / replicate this composition / modify from this example," do not directly reuse these old compositions:

- Conveyor belt with two breakpoints
- Xiaohei inside a content machine pulling the judgment lever
- Xiaohei becoming a funnel sorting traffic/trust/conversion
- Xiaohei slicing a material fish
- Xiaohei guiding the handoff path
- Xiaohei pulling three layers of information sources
- Three Xiaoheis each holding a megaphone/building a bridge/opening a door
- Xiaohei stamping a script toolbox
- Xiaohei holding a sign watching a common pitfalls path

Even for similar themes, use a new metaphor. For example, "handoff path" doesn't have to be a route map — it could be Xiaohei connecting a content tail to a door handle; "one fish many uses" doesn't have to be a fish — it could be Xiaohei pressing one paper ball into several different shapes.
