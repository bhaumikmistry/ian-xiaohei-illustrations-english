# Prompt Examples

These prompts can be copied directly into Codex for use.

## Illustration Planning Only

```text
Use $ian-xiaohei-illustrations — don't generate images yet.
Analyze this article for where illustrations would add value, and output a shot list of about 5 images.
For each image specify:
- Placement (after which paragraph)
- Image theme
- Core meaning
- Structure type
- What Xiaohei is doing in the image
- Suggested elements
- Suggested English annotation labels

<paste article>
```

## Article Inline Illustrations

```text
Use $ian-xiaohei-illustrations to generate 4 Xiaohei absurd inline illustrations for this article.
Requirements: 16:9 landscape, pure white background, black hand-drawn line art, sparse red/orange/blue handwritten English annotations.
Each image covers only one core structure — no PPT infographics, no cute cartoons.

<paste article>
```

## Long Article Illustration Strategy

```text
Use $ian-xiaohei-illustrations to create an illustration strategy for this long article.
Don't distribute illustrations evenly — only pick cognitive anchors: core judgments, input-output loops, before/after comparisons, common pitfalls, handoff paths.
Default 6-8 images, output the shot list first, don't generate images.

<paste article>
```

## Single Viewpoint — One Image

```text
Use $ian-xiaohei-illustrations to generate one 16:9 inline illustration for this viewpoint:

Trust isn't something you shout — it's something you build one piece of evidence at a time.

The image should be absurd yet clean, and Xiaohei must perform the core action.
Maximum 5 English annotations, keep them short.
```

## Workflow Theme

```text
Use $ian-xiaohei-illustrations to generate one image for: "Processing one raw piece of content into three types: traffic, trust, and conversion."
Don't draw a formal flowchart, don't copy the "one fish many uses" old example.
Reinvent a new low-tech metaphor, and have Xiaohei perform the core action.
```

## Edit: Remove Title

```text
Use $ian-xiaohei-illustrations to edit this image.
Remove the "Workflow / Flowchart" title and underline from the top-left corner, keep everything else unchanged.
Do not add any new text or objects.
```

## Edit: Enhance Xiaohei's Participation

```text
Use $ian-xiaohei-illustrations — the direction of this image is right, but Xiaohei feels like decoration.
Keep the core meaning unchanged and regenerate: make Xiaohei the one truly driving the structure.
Make it stranger, but still pure white, clean, and with minimal text.
```

## Generate a Set of Style Samples

```text
Use $ian-xiaohei-illustrations to output 5 Xiaohei inline illustrations on different themes.
Themes should cover: information overload, product validation, content compounding, solo company, trust building.
Generate each one separately, don't combine them into one image.
```
